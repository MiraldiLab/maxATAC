quant-maxATAC: deep neural network models for quantitative transcription factor binding prediction from ATAC-seq
=================================================================================================================

quant-maxATAC predicts quantitative TF ChIP-seq signal (TF binding strength) at 32 bp resolution from
ATAC-seq signal and DNA sequence. See the project README for installation and a quick start.
