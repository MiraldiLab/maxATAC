# Predict

The `predict` function uses a quant-maxATAC model to predict TF binding in a new condition. The user must provide a model and a bigwig file that corresponds to a maxATAC-normalized ATAC-seq signal track.

Quantitative models output a **predicted TF ChIP-seq signal** for every 32 bp bin, on the same scale as the ChIP-seq targets the model was trained on (see [`--target_scale_factor`](./train.md#--target_scale_factor)). Values are non-negative and unbounded (softplus output layer); they are *not* probabilities. Whether a prediction is quantitative or binary is determined entirely by the model file: binary maxATAC v1 models still output 0–1 binding probabilities.

The prediction track can optionally be thresholded into a BED file of TF binding sites using the calibration table generated by [`maxatac threshold`](./threshold.md) (see `--cutoff_file`).

## Example

```bash
maxatac predict -tf CTCF --signal GM12878_IS_slop20_RP20M_minmax01.bw -n GM12878_CTCF
```

or, with an explicit model file (peak calling is skipped unless `--cutoff_file` is also given):

```bash
maxatac predict -m CTCF_quant.h5 --signal GM12878_IS_slop20_RP20M_minmax01.bw -n GM12878_CTCF --cutoff_file CTCF_cross_celltype.tsv
```

## Outputs

| Filename              | Description                                                                                                         |
|-----------------------|---------------------------------------------------------------------------------------------------------------------|
| `<name>.bw`           | Predicted signal track at 32 bp resolution. Overlapping sliding-window predictions are averaged.                    |
| `<name>_peaks.bed`    | Bins with a score ≥ the calibrated threshold, merged into intervals (column 4 = max score). Only written when a calibration table is available and `--skip_call_peaks` is not set. |

## Required Arguments

### `-tf, --tf_name` or `-m, --model`

The user must provide either the TF name that they want to make predictions for or the `.h5` model file they desire. If the user provides a TF name, the model in `~/opt/maxatac/data/models/<TF>/` will be used and the matching `<TF>*_cross_celltype.tsv` calibration table will be picked up for peak calling.

### `-s, --signal, -i`

The ATAC-seq signal bigwig track that will be used to make predictions of TF binding. This should be the `*_minmax01.bw` output of [`maxatac prepare`](./prepare.md).

### `-n, --name, --prefix`

Output filename prefix to use (without extension). Example: `GM12878_CTCF`.

## Optional Arguments

### `--sequence, --seq`

This argument specifies the path to the 2bit DNA sequence for the genome of interest. maxATAC models are trained with hg38 so you will need the correct `.2bit` file. Default: the hg38 `.2bit` file installed by `maxatac data`.

### `-cutoff_file, --cutoff_file`

The threshold calibration table (`<prefix>_cross_celltype.tsv`) written by [`maxatac threshold`](./threshold.md). It maps each target metric value (precision, recall, F1) to the prediction-score threshold that achieves it. For quantitative models the thresholds are on the predicted-signal scale.

* With `--tf_name`, the bundled table in `/data/models/<TF>/` is used unless an explicit `--cutoff_file` is given (an explicit path always wins).
* With `--model` and no `--cutoff_file`, peak calling is skipped and only the bigwig is written.

### `-cutoff_type, --cutoff_type`

The metric whose calibration grid is used to pick the threshold (`Precision`, `Recall`, or `F1`). Default: `F1`.

### `-cutoff_value, --cutoff_value`

The cutoff value for the cutoff type provided; precision, recall, and F1-scores range 0-1. Example: `.7`. Optional for `F1`, where omitting it selects the threshold with the highest F1. The lowest calibration bin that still meets the requested value is used.

### `-skip_call_peaks, --skip_call_peaks`

Skip peak calling at the end of prediction, even when a calibration table is available.

### `--max_zooms`

The number of zoom levels to compute for the prediction bigWig file. Zoom levels are pre-computed summary statistics that let genome browsers (IGV, UCSC Genome Browser) zoom in and out of a region quickly; fewer levels mean slower loading in browsers, more levels mean more memory during writing. Valid range: `0`-`10`. Default: `10`. Note: a value of `0` produces a bigWig that is not compatible with other bigWig tools (e.g. deepTools) and cannot be visualized in IGV or the UCSC Genome Browser. See the [pyBigWig README](https://github.com/deeptools/pyBigWig/blob/master/README.md) for details.

### `-o, --output`

Output directory path. Default: `./prediction_results`

### `-bl, --blacklist`

The path to a BED file of regions to exclude from prediction. Default: maxATAC-defined blacklist.

### `--bed, --peaks, --regions, --roi, -roi`

The path to a BED file that contains the genomic regions to focus TF predictions on. These regions will be used to build the prediction windows instead of tiling the whole chromosome.

### `-w, --windows`

The windows to use for prediction. These windows must be 1,024 bp wide and have a consistent step size. They replace the windows generated de novo.

### `--batch_size`

The number of regions to predict on per batch. Default: `10000`. Decrease this value if you are having memory issues.

### `--threads`

The maximum number of chromosomes to predict in parallel. Each process loads the full model and the 2bit genome, so memory, not CPU count, usually sets the practical limit; lower this value if prediction runs out of memory. The pool is also capped by the number of chromosomes requested and the available CPUs. Default: `24`

### `--step_size`

The step size to use for building the prediction intervals. Overlapping prediction bins will be averaged together. Default: `INPUT_LENGTH/4` = 256 bp, where `INPUT_LENGTH` is the maxATAC model input size of 1,024 bp.

### `--ablation_type`

Ablate part of the model input before prediction, for diagnosing what the model relies on. `signal` replaces the ATAC-seq signal channel with a fixed value (`--ablation_value`); `sequence` dinucleotide-shuffles the DNA sequence channels. Choices: `none`, `signal`, `sequence`. Default: `none`.

### `--ablation_value`

The fixed value substituted into the ATAC-seq signal channel when `--ablation_type signal` is used. Default: `0.0`.

### `-cs, --chrom_sizes, -chrom_sizes, --chromosome_sizes`

The path to the chromosome sizes file. This is used to generate the bigwig signal tracks. Default: hg38 chromosome sizes.

### `-c, -chroms, --chromosomes`

The chromosomes to make predictions on. Our models do not currently consider chromosomes X or Y. You should not predict in chrX or chrY unless you know your bigwig contains these chromosomes. Default: autosomal chromosomes 1-22.

### `--loglevel`

Logging level (`fatal`, `error`, `warning`, `info`, `debug`). Default: `info`.

### `--quant`

Deprecated and hidden from `--help`. It is accepted for backwards compatibility but has no effect: quantitative prediction follows from the model file.
